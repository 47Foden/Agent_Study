# Writer Agent

## 1. 목적

Pro Agent와 Critic Agent의 토론 결과를 **중립적으로 종합**하여 최종 적격성 판정 및 리스크 진단 보고서를 작성한다.

## 2. 입력

- Pro Agent의 지원 가능 주장과 긍정적 근거
- Critic Agent의 결격·위험 반박과 원문 인용 근거
- 최대 2~3회 왕복 토론에서 도출된 쟁점

## 3. 최종 보고서 구성

| 항목 | 내용 |
| --- | --- |
| 신청 가능 여부 | 양측의 근거를 종합한 최종 판단 |
| 치명적 결격 사유 3가지 | 주요 탈락 위험 요소 3가지 정리 |
| 보완 필요 사항 | 신청 전 보완하거나 확인해야 할 사항 |

## 4. 처리 흐름

```text
Pro / Critic 토론 결과 수신
            ↓
양측 주장과 반박 근거 종합
            ↓
적격성 및 주요 리스크 정리
            ↓
최종 판정·리스크 진단 보고서 작성
```

## 5. 구현 시 검토할 항목

- 상충하는 주장과 근거를 어떤 기준으로 종합할 것인가?
- 판정에 필요한 정보가 부족할 때 어떻게 표시할 것인가?
- 보고서의 판단 근거를 원문 페이지·조항과 어떻게 연결할 것인가?

위 질문은 구현 단계의 설계 과제이며, 연구계획서에 세부 판정 규칙은 명시되지 않았다.
